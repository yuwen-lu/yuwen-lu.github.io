# yuwen.io/calligraphy

Written by `tools/export-yuwen.js` in [p5-brush](https://github.com/yuwen-lu/p5-brush). Don't edit these files here: change p5-brush, then run from its folder

    node tools/export-yuwen.js ../yuwen-lu.github.io/public/calligraphy

The script replaces this folder. `index.html` is the twelve works and `how-it-works.html` is the tracer demo; `vercel.json` at the root of this site serves them at /calligraphy and /calligraphy/how-it-works.
