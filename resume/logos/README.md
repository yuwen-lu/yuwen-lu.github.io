# Company logo sources

These assets are retained from an earlier layout experiment. The current
template does not render company logos.

- **Contra Labs**: the four SVG quadrants and rotations from the symbol on
  <https://contralabs.com/>, assembled into a standalone vector mark with the
  site's dark neutral fill. The official favicon was used as a visual reference.
- **Krea**: unmodified black icon from the official press kit,
  <https://www.krea.ai/press/krea/krea-icon-black.svg>.
- **Midjourney**: the official organization's GitHub avatar,
  <https://github.com/midjourney>, downloaded from
  <https://avatars.githubusercontent.com/u/61396273?s=256&v=4>.
- **Apple / Google**: monochrome Simple Icons marks distributed with the
  already-installed `react-icons/si` package, serialized as SVG. Upstream:
  <https://github.com/simple-icons/simple-icons>.
